PASO 1 DE 6

Instalar y abrir

Unos minutos, y solo la primera vez.

LO QUE NECESITAS

Cinco cosas

  • Docker: corre todo el estudio
  • Google Chrome, para grabar
  • Unos 6 GB libres
  • El PDF del libro, con texto seleccionable
  • Audífonos, para oír las citas
INSTALAR

Tres comandos

Windows: desde WSL
$ git clone https://github.com/mbuitragocUNAL/videolectura-studio-unal
$ cd videolectura-studio-unal
$ ./estudio abrir
Estudio en http://localhost:8100
ABRIR

localhost:8100

  • Abre en Chrome
  • Sin lecturas todavía
  • Sigue: Nueva lectura
EL DÍA A DÍA

Apagar y actualizar

$ ./estudio cerrar
# tus lecturas y tomas quedan en lecturas/
$ git pull
$ ./estudio abrir
SIGUIENTE · PREPARAR LA LECTURA
